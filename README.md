## Dataset

This project uses the **100-class ImageNet-1k subset** provided for the COL775 Deep Learning assignment at IIT Delhi.

The dataset is used for image classification experiments involving ResNet-18 and different normalization schemes.

### Dataset Source

The dataset is hosted on Kaggle:

- **Kaggle:** [A1-COL775-ResNet](https://www.kaggle.com/datasets/gladiatorshield/a1-col775-resnet)

The dataset is hosted externally and is not included in this repository.

Refer to the dataset page for download instructions and licensing information.

### Model Checkpoints

The trained ResNet-18 model checkpoints for all seven configurations (Baseline, NN, BN, IN, BIN, LN, and GN) are hosted on Hugging Face:

[Download Model Checkpoints](https://huggingface.co/NepurnTyagi/resnet-normalization-study)

The Hugging Face repository includes the final model checkpoints for all seven configurations.
